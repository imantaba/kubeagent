# Adopters

Organizations and individuals using kubeagent. If kubeagent is useful to you,
adding yourself here is the single most helpful non-code contribution you can
make: it tells other operators the project is used in real clusters, and it is
the evidence a foundation asks for when a project applies for donation.

To add yourself, open a pull request adding a row to the table. Only add an
entry for an organization if you are authorized to do so. A link and a one-line
description of how you use it are welcome but optional; "Production" /
"Testing" / "Development" is enough.
