# Code of Conduct

kubeagent has adopted the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).
It applies to everyone taking part in the project — maintainers, contributors,
and anyone opening an issue or comment — in every project space: this
repository, its issues and pull requests, and any chat, call, or event held in
the project's name.

## The short version

As contributors and maintainers of this project, and in the interest of
fostering an open and welcoming community, we pledge to respect all people who
contribute through reporting issues, posting feature requests, updating
documentation, submitting pull requests or patches, and other activities.

We are committed to making participation in this project a harassment-free
experience for everyone, regardless of level of experience, gender, gender
identity and expression, sexual orientation, disability, personal appearance,
body size, race, ethnicity, age, religion, or nationality.

Examples of unacceptable behavior include:

- The use of sexualized language or imagery.
- Personal attacks.
- Trolling or insulting/derogatory comments.
- Public or private harassment.
- Publishing others' private information, such as physical or electronic
  addresses, without explicit permission.
- Other unethical or unprofessional conduct.

Maintainers have the right and responsibility to remove, edit, or reject
comments, commits, code, wiki edits, issues, and other contributions that are
not aligned with this Code of Conduct. By adopting this Code of Conduct,
maintainers commit themselves to applying these principles fairly and
consistently to every aspect of managing this project. Maintainers who do not
follow or enforce the Code of Conduct may be permanently removed from the
project team.

This applies both within project spaces and in public spaces when an individual
is representing the project or its community.

The authoritative text is the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md);
where this summary and that document differ, that document governs.

## Reporting

Report abusive, harassing, or otherwise unacceptable behavior privately to the
project maintainers listed in [MAINTAINERS.md](MAINTAINERS.md), via GitHub
direct message or by opening a
[private security advisory](https://github.com/imantaba/kubeagent/security/advisories/new)
on this repository — the advisory form is private to the reporter and the
maintainers, so it works as a confidential channel even though the matter is
not a vulnerability.

If your report concerns a maintainer, or you are not comfortable reporting to
the maintainers, report it to the CNCF Code of Conduct Committee at
<conduct@cncf.io>, which accepts reports about projects in the wider cloud
native community.

Reports are handled confidentially. The maintainers will acknowledge a report
within **three working days**, investigate, and respond with the action taken.
Possible responses range from a private warning through to a temporary or
permanent ban from project spaces and removal from the maintainer group.
Maintainers are obligated to keep the identity of a reporter confidential.

> kubeagent is not currently a CNCF project. It has adopted the CNCF Code of
> Conduct as its own text; enforcement is carried out by the project
> maintainers. Should the project be accepted into the CNCF, enforcement
> passes to the CNCF Code of Conduct Committee.
