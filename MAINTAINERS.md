# Maintainers

Maintainers have write access to the repository and are responsible for
reviewing and merging changes, cutting releases, and enforcing the
[Code of Conduct](CODE_OF_CONDUCT.md). How maintainers are added and removed is
described in [GOVERNANCE.md](GOVERNANCE.md).
